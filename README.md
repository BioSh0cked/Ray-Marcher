
# Ray Marcher

A Ray Marching visual simulator built in touchdesigner.


## Features

- Event Horizon
- Particle generation
- Schwarzschild SDF
- Radial Decay


## Usage

1. Install TouchDesigner
2. Install Source or RayMarcher.toe
3. Launch .toe file and press F1
4. Profit?
